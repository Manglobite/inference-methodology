## Результаты

ЗАПОЛНИТЬ: сводная таблица по каноническим прогонам. Источники —
`docs/results-tables.md` (человекочитаемые таблицы) и `docs/results.json`
(машинно-читаемая сводка со списком канонических/контрольных прогонов);
сырые прогоны — `results/<run_id>/`. Канонический результат — агрегат по
повторам **на ступень** (каноничность per-ступень): ступень входит только если
она comparable (`completion_is_fixed` + `finish_reason = length` +
`step_comparable`) и по ней **n ≥ 3** уникальных `ok`-прогонов (**медиана +
min/max**, с указанием `n` и списка `run_id`); ступени с `n < 3` помечаются
`limited` и выводятся отдельно, вне основных таблиц/графиков. Статус прогона по
генерации — `fixed`/`mixed`/`variable`.
Норма — в [METHODOLOGY.md](../../METHODOLOGY.md) §11.1 (для скелета;
после копирования кейса путь — `../methodology/METHODOLOGY.md`).
Производные величины (проценты, Δ) помечайте как **вычислено**,
интерпретацию отделяйте от фактов.

При наличии A/B-серии приведите парный A/B-Δ (Δ = 100·(B−A)/A по совпадающим
ступеням, медиана Δ, `n_pairs`, `sign_consistency`) из отчёта и
`docs/results.json` (`ab_delta`, ключ `"profile|order"`). При наличии телеметрии
мощности — оценка энергетики ступени (J/request = `energy_j`, J/output-token из
`telemetry.csv`; секция «Энергия и мощность» отчёта), помеченная как **оценка**;
`energy_dynamic_j` вычитает baseline из idle-окна (медиана суммарной мощности за
`IDLE_WINDOW_S` перед первым запросом, fallback — минимум по прогону; источник —
`idle_baseline_source`); если телеметрии мощности нет — это не блокер,
зафиксируйте явное «нет данных».

## Публикация

ЗАПОЛНИТЬ после прохождения барьера: `scripts/check-public.sh` (ожидается
`OK: no private markers found`), санитайз публикационной копии
`scripts/sanitize-results.sh --in-place` (оба скрипта скопированы из
`methodology/scripts/publish/`). Санитайз с `--in-place` деструктивен: применяйте
его к публикационной копии дерева или предварительно сделайте архив/бэкап
исходных `results/`. Барьер покрывает `/home/<user>/`, `/root/`,
`/Users/<user>/`, `/mnt/`, RFC1918, `sk-[A-Za-z0-9_-]{13,}`, `Authorization: Bearer` и
`api_key`/`secret`/`token`; имена хостов baseline не ловит — их добавляют через
`PUBLIC_DENY_FILE`. В публикуемых текстах — только относительные пути;
абсолютные домашние пути, имена хостов и внутренние IP не публикуются.
Веса модели не коммитятся.
