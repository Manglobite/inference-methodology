# Аппаратная и программная конфигурация стенда

> Шаблон. Замените `<HARDWARE>` и заполните таблицы фактами со своего стенда.
> Все значения указывайте с источником (лог, `nvidia-smi`, `/proc/meminfo`);
> если величина не зафиксирована — напишите это явно.

## GPU

Порядок устройств — **по шине PCI** (`CUDA_DEVICE_ORDER=PCI_BUS_ID`); он же
используется во всех профилях кейса.

| Индекс | Модель | PCI bus | VRAM | Compute | Роль в кейсе |
| ---: | --- | --- | ---: | ---: | --- |
| CUDA0 | `<HARDWARE>` | `<pci>` | `<vram>` | `<sm>` | ЗАПОЛНИТЬ |
| CUDA1 | | | | | |

UUID карт могут отличаться на другом экземпляре; проверяйте `nvidia-smi -L`.
